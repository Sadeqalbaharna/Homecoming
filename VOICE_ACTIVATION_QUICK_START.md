# 🎤 Quick Start: "Hey Kai" Voice Activation

## Enable Voice Activation

1. **Open Settings**
   - Tap Kai's avatar
   - Select "Settings" from the menu

2. **Enable Voice Activation**
   - Find "🎤 Voice Controls" section
   - Toggle ON "Hey Kai" Voice Activation
   - Grant microphone permission if prompted

3. **Wait for Initialization**
   - Look for "✅ [VOICE ACTIVATION] Initialized and ready" in logs
   - Takes 3-5 seconds to start listening

## How to Use

### Quick Question
```
You: "Hey Kai, what's the weather today?"
     └─ Chat opens automatically
     └─ AI responds immediately
```

### Start Recording
```
You: "Hey Kai" [pause for 1 second]
     └─ Chat opens
     └─ Recording starts automatically
     └─ Speak your full message
```

### Complex Commands
```
You: "Hey Kai, remind me to call mom at 3 PM"
     └─ Processes full instruction
     └─ Creates reminder
```

## Tips for Best Results

✅ **DO:**
- Speak clearly and at normal volume
- Pause briefly after "Hey Kai" if you need to think
- Use a quiet environment
- Keep phone within 3 feet

❌ **DON'T:**
- Whisper (may not be detected)
- Shout (reduces accuracy)
- Use in very noisy environments
- Expect instant response (needs 1-3 seconds)

## Wake Word Variations

All of these work:
- "Hey Kai"
- "Hey Kay" 
- "Okay Kai"
- "Ok Kai"

## Battery Saving

Voice activation uses ~5-10% additional battery per day.

**To save battery:**
1. Disable when not needed (Settings → Toggle OFF)
2. Use WiFi instead of mobile data
3. Close other battery-intensive apps

## Troubleshooting

### Not responding to "Hey Kai"?
1. Check Settings → Voice Activation is ON
2. Verify microphone permission granted
3. Check internet connection (needs WiFi/data)
4. Try speaking louder and clearer

### False activations?
1. Move phone away from speakers/TV
2. Reduce background noise
3. Temporarily disable if needed

### Slow to respond?
1. Check internet speed
2. Switch to WiFi
3. Restart app

## Quick Test

1. Enable voice activation in Settings
2. Wait 5 seconds
3. Say "Hey Kai, test" 
4. Chat should open with your message
