# 🎤 Quick Start: "Hey Kai" Voice Activation

## Enable Voice Activation

**Method 1: Quick Toggle (Recommended)**
1. Look at the top-right corner of Kai's overlay
2. Tap the microphone icon
   - 🟢 Green with glow = Listening
   - ⚫ Grey = Off
3. That's it! Start saying "Hey Kai"

**Method 2: Settings Menu**
1. Tap Kai's avatar
2. Select "Settings" from the menu
3. Toggle ON "Hey Kai" Voice Activation
4. Grant microphone permission if prompted

## Visual Indicator

Look for the microphone icon in the top-right corner:
- 🎤 **Green with glow** = Actively listening for "Hey Kai"
- 🔇 **Grey** = Voice activation disabled

**Tap the icon to instantly toggle on/off!**

## How to Use

### Quick Question
```
You: "Hey Kai, what's the weather today?"
     └─ Chat opens automatically
     └─ AI responds immediately
```

### Start Recording
```
You: "Hey Kai" [pause for 1 second]
     └─ Chat opens
     └─ Recording starts automatically
     └─ Speak your full message
```

### Complex Commands
```
You: "Hey Kai, remind me to call mom at 3 PM"
     └─ Processes full instruction
     └─ Creates reminder
```

## Tips for Best Results

✅ **DO:**
- Speak clearly and at normal volume
- Pause briefly after "Hey Kai" if you need to think
- Use a quiet environment
- Keep phone within 3 feet

❌ **DON'T:**
- Whisper (may not be detected)
- Shout (reduces accuracy)
- Use in very noisy environments
- Expect instant response (needs 1-3 seconds)

## Wake Word Variations

All of these work:
- "Hey Kai"
- "Hey Kay" 
- "Okay Kai"
- "Ok Kai"

## Battery Saving

Voice activation uses ~5-10% additional battery per day.

**To save battery:**
1. **Quick toggle**: Tap microphone icon to turn off instantly
2. **Settings toggle**: Disable in Settings when not needed
3. Use WiFi instead of mobile data
4. Close other battery-intensive apps

## Troubleshooting

### Not responding to "Hey Kai"?
1. Check Settings → Voice Activation is ON
2. Verify microphone permission granted
3. Check internet connection (needs WiFi/data)
4. Try speaking louder and clearer

### False activations?
1. Move phone away from speakers/TV
2. Reduce background noise
3. Temporarily disable if needed

### Slow to respond?
1. Check internet speed
2. Switch to WiFi
3. Restart app

## Quick Test

1. Enable voice activation in Settings
2. Wait 5 seconds
3. Say "Hey Kai, test"
