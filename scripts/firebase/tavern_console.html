🛠 Maintenance
One-time / occasional sync jobs. Safe to re-run anytime — each only touches entries that actually changed.
Mirrors every account's baked avatarUrl (Firestore users/*) into RTDB /avatars, which is what the Map tab's guest sprites read from. Run this once after deploying functions, or anytime a guest's avatar isn't showing up correctly on the floor plan.
A table can be left showing "occupied" (and its visit stuck "open" forever, triggering the Tavern Alerts "tables open past 45m" warning) if a guest got cleared out through an older or partial close path that didn't fully clean up /tables and /visits. This scans every table for that mismatch — occupied but nobody actually seated — and any leftover open visit not tied to a real occupied table, and closes them out. Does not touch tables that are genuinely occupied right now.
