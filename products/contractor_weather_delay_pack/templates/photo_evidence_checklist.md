# Weather Delay Photo Evidence Checklist

Use this checklist when weather affects site work. The goal is not pretty photos — it is useful proof.

## Take photos/videos of

- [ ] Overall site condition
- [ ] Affected work area
- [ ] Access roads / blocked access
- [ ] Standing water / mud / flooding
- [ ] Unsafe wind/rain/lightning condition where visible
- [ ] Materials protected or damaged
- [ ] Equipment idle or unable to access work area
- [ ] Crew reassigned or work area inactive, if appropriate
- [ ] Weather app/source screenshot with timestamp
- [ ] Any instructions received from GC/owner/inspector

## For each photo/video, record

- [ ] Date
- [ ] Time
- [ ] Location/area
- [ ] Who captured it
- [ ] What it shows
- [ ] Which delay event ID it supports
- [ ] Where the original file is stored
- [ ] Whether it has been backed up

## Good evidence habits

- Take wide shots and close shots.
- Include fixed landmarks when possible.
- Do not rely on memory — log the photo the same day.
- Keep original files; do not only keep compressed chat-app copies.
- Save proof of sent notices next to the photos/logs.
