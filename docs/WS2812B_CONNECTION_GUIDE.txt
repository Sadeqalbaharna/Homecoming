STEP-BY-STEP WIRING PROCESS:
══════════════════════════

Step 1: POWER SETUP
┌─────────────────────────────────────────────────────────┐
│ 1. Connect 5V 20A supply negative to breadboard GND    │
│ 2. Connect 5V 20A supply positive to breadboard +5V    │  
│ 3. Connect Pi GND (Pin 6) to breadboard GND rail       │
│ 4. DO NOT connect Pi 5V to supply (control only!)      │
└─────────────────────────────────────────────────────────┘

Step 2: SIGNAL CONNECTIONS  
┌─────────────────────────────────────────────────────────┐
│ 1. Pi GPIO 18 (Pin 12) → 330Ω resistor → Main DIN     │
│ 2. Pi GPIO 13 (Pin 33) → 330Ω resistor → Accent DIN   │
│ 3. Pi GPIO 12 (Pin 32) → 330Ω resistor → Ambient DIN  │
└─────────────────────────────────────────────────────────┘

Step 3: LED STRIP CONNECTIONS (For Each Strip)
┌─────────────────────────────────────────────────────────┐
│ Red Wire (VCC) → +5V Power Rail                        │
│ White/Black (GND) → GND Power Rail                      │  
│ Green Wire (DIN) → Resistor → Pi GPIO Pin              │
└─────────────────────────────────────────────────────────┘
